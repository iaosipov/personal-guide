# Методы

> Bottleneck: **W и M2** — ритм слотов + устойчивое применение методов. Оба удерживают ступень 2.
> На ступени 2 достаточно **двух методов** одновременно. Больше — ресурс не тянет.

## Методы под bottleneck M2 (методы саморазвития не встроены стабильно)

### METHOD.001 — Учёт времени (CAT.003, степень 1→2)

**Зачем:** без учёта остальные методы не измеряются. Это фундамент.

**Can-do (степень 1):**
- Трекер запущен перед каждым слотом.
- ≥5 ч инвестированного времени на неделе.
- Помидорки 25+5 мин фиксируются в SingularityApp.

**Как встраивается в твою работу:**
- Проект «Саморазвитие» в SingularityApp = слоты на чтение руководства, разбор заметок, рефлексию.
- Проект «Работа» = всё остальное (WP, встречи, ДЗ Bitrix24).
- Первая разблокировка: учёт покажет, что реальный ресурс не «нет времени», а «не выделено явно».

**Главное:** включать трекер перед работой, даже если потом забросишь — запись о том, что не удержался, важнее пустой недели.

### METHOD.003 — Систематическое медленное чтение (CAT.003, степень 1)

**Зачем:** книга «Системное саморазвитие» читается уже сейчас (раздел 8, гл. 8.5) — нужно перевести чтение из «просматриваю» в «осваиваю методом».

**Can-do (степень 1):**
- ≥3 образовательных заметки на неделе из текущей книги.
- Чтение с двойным фокусом: читаю + пишу заметку на полях (Obsidian, Zotero).
- Критерий закрытия: заметка зафиксирована, а не «прочитал страницу».

**Как встраивается в твою работу:**
- Утром до 11:00 — слот «Системное саморазвитие», 25 мин.
- Заметки из книги → Zotero (3 цвета: 🟡 суть / 🟢 беру в работу / 🔵 опора) → Obsidian.
- Прямая связь: раздел 8 «Личность и агент» → прямо в работу над IWE + пост в блог.

## Правило движения

Степень мастерства по каждому методу — **не более 2 (Умение)** на этой ступени. Прыжок «быстро освою 3 степень в письме» типично ломает ритм: ресурс уходит в один метод и остальные проседают.

## Критерий перехода на ступень 3

**Двойной gate (PD.FORM.003 §3 + FORM.089 §5.2):**
- Эпизодическая практика переросла в ежедневную (≥5 слотов/нед в течение 2+ недель подряд).
- W-индекс достиг 3 (есть рабочий язык «я — система», описываешь свой ритм в системных терминах, не эмоциональных).

Пока хотя бы один критерий не выполнен — остаёмся на Практикующем.
