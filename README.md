# Персональное руководство для пилота iaosipov

## Структура этого репо

Это твоя персональная среда развития. Здесь живут:

- **`daily/2026-06-08.md`** — руководство на текущий день: одно действие, один вопрос для рефлексии.
- **`weekly/2026-W24.md`** — руководство на неделю: ритм, гипотеза, слоты.
- **`history/`** — архив рефлексий (файлы `YYYY-MM-DD-reflection.txt`).
- **`profile.md`** — текущий RCS-профиль (ступень, bottleneck, неудовлетворённость).
- **`worldview.md`** — нарративная дуга: где сейчас, куда двигаемся.
- **`methods.md`** — активные методы под текущий bottleneck.

## Цикл работы

**Каждый день** — открыть `daily/<сегодня>.md`, прочитать одно действие, закрыть слот, добавить одну строку в `history/`.

**Каждую неделю** (понедельник утром) — руководство пересобирается автоматически.

## Рефлексия

Рефлексия — текстовый файл в `history/YYYY-MM-DD-reflection.txt`. Достаточно одного абзаца:
- Что закрыл — что не закрыл сегодня.
- Что мешало / что помогало (внешнее или внутреннее).

Портной читает рефлексии при следующем рендере и адаптирует контент.

## Команда пересборки

`/personal-guide-render` (в Claude Code) пересобирает все файлы руководства по актуальному RCS-профилю.
