# Персональное руководство. Ступень 1: Случайный

> Ты здесь, потому что пропустил занятия 4 дня. Это нормально. Главное сейчас — не план, не система, а один шаг. Этот документ поможет сделать его сегодня.

## Структура руководства

Этот репо — твоя персональная среда развития на ближайшие 2–3 недели. Что здесь живёт:

- **`daily/2026-06-07.md`** — руководство на сегодня: одно действие, один вопрос для рефлексии.
- **`profile.md`** — твой текущий RCS-профиль (ступень, узкое место, что тебя останавливает).
- **`worldview.md`** — нарративная дуга: где ты сейчас, куда двигаемся.
- **`methods.md`** — один активный метод под твой bottleneck.
- **`history/`** — архив рефлексий (файлы `YYYY-MM-DD-reflection.txt`).

## Цикл работы

**Каждый день:** открыть `daily/<сегодня>.md`, прочитать, закрыть 1 помидорку (25 мин), добавить одну строку в `history/`.

**Когда устану:** это нормально. Пропуск — не провал. Провал — решить, что всё кончено.

## Рефлексия

Рефлексия — текстовый файл в `history/YYYY-MM-DD-reflection.txt`. Достаточно одного абзаца:
- Что закрыл сегодня
- Что мешало или помогало

Портной читает рефлексии и адаптирует план под них.

## Пересборка руководства

Каждый понедельник утром руководство пересобирается автоматически под твой текущий RCS-профиль. Просто открой `daily/` и продолжи работу.
